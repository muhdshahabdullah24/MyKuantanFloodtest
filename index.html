    ⚠️ Real Flood Alert Simulation

      This system uses the saved location, analysis radius, and mapped flood polygons together with live weather conditions.

      🗺️ Flood Risk Classification

      The map uses the existing GeoJSON flood-risk dataset and checks whether the saved point plus the selected radius intersects a mapped area.

      • Category 1Very Low
      • Category 2Low
      • Category 3Moderate
      • Category 4High
      • Category 5Very High

      A warning is only triggered when the selected radius overlaps a Category 4 or Category 5 zone.

      🌧️ Trigger Weather Conditions

      Open-Meteo is checked for the dangerous weather codes used in the alert logic:

      • 65 - Heavy rain
      • 82 - Violent rain showers
      • 95 - Thunderstorm
      • 96 - Thunderstorm with hail
      • 99 - Thunderstorm with heavy hail

      Current Alert Logic

      Saved area overlaps Category 4 or 5 AND dangerous weather code → flood alert

      • Category 4 + heavy rain⚠️ High Flood Risk Alert
      • Category 5 + thunderstorm🚨 Very High Flood Risk Alert
      • Category 1–3Not an automatic push alert

      Notifications are deduplicated per saved location, risk category, weather code, and time window so the same alert is not sent repeatedly.
